ShopForce User Guide

SFMC MobilePush demo app for Android — download, connect, register, and send messages.

Use this guide to install ShopForce, connect it to your own Marketing Cloud demo account or the shared S50 Demo business unit, register as a contact, and send test push / inbox messages.

Android only. This is a sideloaded demo APK, not a Play Store listing. Values you enter in the app are stored only on your device.

1. Download the app

On your Android phone, scan the QR code or open either URL below.

Install on Android

  1. If an older ShopForce build is installed, uninstall it first so you pick up the latest bottom menu (Home, Explore, Cart, Saved, Messages, Profile).
  2. Allow the download if the browser asks.
  3. Open the downloaded shopforce.apk file.
  4. Enable Install unknown apps for that browser when Android asks.
  5. Tap Install, wait, then tap Open.

2. Add Marketing Cloud credentials

On first launch, ShopForce shows a two-step setup bar: 1. Connect then 2. Register. The Connect screen is Connect Your MC Instance.

Connect Your MC Instance — paste App ID, Access Token, Server URL, and MID

Choose which account to use

OptionWhen to use itMID
Your own demo account You already have a Marketing Cloud demo / sandbox BU and can open Setup. Your BU’s MID from Setup → Company Settings → Account
S50 Demo You are running the shared S50 demo and have (or can get) an SFMC user on that BU. 500007709

S50 Demo access: If you do not already have an SFMC user on the S50 Demo business unit (MID 500007709), do not guess credentials. Reach out to your Team member or Swarm Lead and ask them to provision SFMC access. Then copy the MobilePush app values from that BU.

Where to copy the values in Marketing Cloud

  1. Log in to Marketing Cloud (your demo BU, or S50 Demo after access is granted).
  2. Go to Setup → Apps → Mobile Push.
  3. Open the existing MobilePush app for ShopForce, or create one:
    • Choose Create / Create New App
    • Name it something like ShopForce Demo and save
  4. Copy App ID, Access Token, and Server URL (also called App Endpoint).
  5. Copy MID from Setup → Company Settings → Account — for S50 Demo this is 500007709.

Each tester should use credentials from a BU they are allowed to send from. Do not paste someone else’s Access Token into your phone unless they have explicitly shared a demo app for this purpose.

Tap Save & Continue. The app checks that App ID is a UUID and that Server URL looks like https://….marketingcloudapis.com/. If a field is wrong, fix it and save again. Setup then slides to Register.

3. Register in the app

On Create Your Account, enter the details Marketing Cloud will use as your contact.

Register with email, phone, first name, and last name
  1. Email Address (required) — this becomes your Contact Key in Marketing Cloud. Use the same email you will look up when sending.
  2. Phone Number — include country code if you can; at least 10 digits.
  3. First Name and Last Name — stored on the device and shown on Profile. First name is used in the home greeting.
  4. Tap Register & Continue. You should see a short “You’re registered” success overlay, then Home.
  5. When Android asks, Allow notifications for ShopForce. You can also turn this on later in Profile → Allow notifications.

After registration you land on Home. The bottom menu is Home · Explore · Cart · Saved · Messages · Profile. Cart stays in the tab bar (you can also open it from the bag icon on Home).

Home after registration — Cart remains in the bottom menu

4. Review your details in Profile

Open the Profile tab, then expand User Details. Confirm what you registered:

  • Email
  • Phone
  • First Name / Last Name
  • Contact Key (same as email)
  • Registration status should read Registered ✓

Expand App if you want to confirm MID and that MobilePush is Configured. Use Allow notifications in Preferences so the device can receive push.

Profile → User Details — confirm email, phone, name, and Contact Key

5. Send messages from your demo instance

Send from the same BU whose App ID you pasted in step 2 (your demo or S50 Demo MID 500007709).

Before you send

  1. In the app, Profile → Allow notifications is on, and Android system settings also allow ShopForce notifications.
  2. In Marketing Cloud, open Mobile Studio → MobilePush (or Contact Builder) and look up the contact by Contact Key = the email you registered.
  3. Wait until that contact’s device shows as Registered. A brand-new install can take a short time; if it stays Not Registered, open the app once more, toggle notifications, and search again. After uninstall, always send to the new contact/device — the old FCM token is dead.

Send a test from MobilePush

  1. In MobilePush, create or open a message.
  2. Choose the send type:
    • Alert (push only) → appears in the app under Messages → Notifications, and as a system notification.
    • Alert + Inbox or Inbox Only → appears under Messages → Inbox messages. Push-only alerts do not land in Inbox.
  3. Target the contact by Contact Key (your registered email), then send.
  4. Optional: set OpenDirect / App URL to a ShopForce deep link such as shopforce://product/af001 so tapping the message opens a product.
  5. Open ShopForce → Messages. Pull down to refresh if the inbox is empty.
Messages tab — Notifications for push alerts, Inbox messages for SFMC inbox

You can also send from Journey Builder with a MobilePush activity. Use the same MobilePush app, the same Contact Key, and Alert + Inbox if you want the message in the in-app inbox.
